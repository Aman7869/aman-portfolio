## 🛠️ GitHub Pages Free Deployment

1. **Commit and Push**:
   ```bash
   git init
   git add .
   git commit -m "Deploy Aman Kaithwas Senior Developer Portfolio"
   git remote add origin https://github.com/amankaithwas/portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. **Enable Pages**:
   - Navigate to your repository settings on GitHub -> **Pages**.
   - Select `main` branch and `/ (root)` folder -> click **Save**.
   - Your site will be online at `https://amankaithwas.github.io/portfolio/`.

3. **Link to LinkedIn**:
   - Add your GitHub Pages link to your LinkedIn profile website header and **Featured** section.
